- 南坡桃花围成一圈 = 程序化，不是仙宫。秋天应收成东西两丛，中间让路给迎仙长阶。

## 先生尺子（不达标就不停）

1. 墙、檐、顶是一套房子，不是三件漂着的零件。
2. 近看有材质，中看有关系，远看有燕云气（细腻）+ 黑神话光（沉郁）。
3. 没有「建模味」的平顶盒子 / 透光黑腔。
4. 超分必须是**写实神经重构**。动漫 ESRGAN 不算 DLSS，不进正片。
5. 关系没对齐之前不冲 3000 件。
