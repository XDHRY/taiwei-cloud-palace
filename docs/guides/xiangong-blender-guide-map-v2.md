## 现码必须先修的硬伤

`hall()` 现在 `columns = max(4, int(width/1.7)+1)`，正殿 width=14.4 → 9 柱 8 间。中轴上有柱，门开不了。必须改成奇数开间、偶数柱列：正殿 7 间 8 柱（或 5 间 6 柱）。当心间最宽，次间、尽间递减。

`bracket()` 没有角铺作。转角柱现在套正面正交斗拱，翼角会假。必须单独做 45° 角华栱 / 角昂 / 由昂 / 宝瓶。

`roof_xyz()` 用 `(1-t)^1.15 + 0.18 t^5 + 0.38 t^7` 连续曲，角上像清式南式飞檐。改成分段举折：殿阁举高 = 进深/3，各槫依次折 1/10、1/20、1/40。

`OVERHANG_RATIO = 0.40` 偏短。黑神话山西扫描体感约 0.52–0.58 柱高。

## 建议改码顺序（仍在原文件上）

1. `hall()` 开间奇偶 + 金柱。不改这个，门和当心间全错。
2. `bracket()` 零件化 + 通长昂；转角走 `corner_bracket()`。
3. `roof_xyz()` 举折折线；`OVERHANG_RATIO` → 0.55；正殿改歇山重檐。
4. `roof()` 鸱吻按 06 轮廓、走兽按 07 队列、椽按 11 双层。
5. `terrace()` 须弥线脚 + 螭首 + 丹陛。
6. `door_pair()` 正殿改格扇；仪门才用门钉。
