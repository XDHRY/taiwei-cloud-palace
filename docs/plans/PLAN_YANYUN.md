# 太微云宫 · 燕云转向改造计划

2026-09-13 先生美学判决：「建模味太重，没有黑神话那种质感，缺乏燕云江南的细腻。
建模风格全面转向燕云十六声，氛围参照黑神话悟空。大规模增加组件，大幅提高建模质量。」

## 一、自诊病清单（代码审计 + 成片抽帧双重确认）

### A. 材质太平（"建模味"首凶）
- 关键材质 `tile 琉璃瓦` / `red 朱漆` / `roof 瓦底` 是**纯平滑色**，连 procedural 都没挂。
- 挂了的材质也只是**单层 Noise→色带→Bump**：
  - 无多尺度叠加（真实材质有大中小三层纹理）；
  - 无**方向性做旧**（真实建筑上浅下深、水边深色、墙根苔痕、风口侵蚀）；
  - 色带线性过渡，无斑块、无污渍团；
- 粉墙 (.73,.77,.66) 太干净——江南白墙应有雨渍、泛碱、墙根青黑。

### B. 缺"活气"（燕云的灵魂是有人间烟火）
- 庭院空荡：无石桌石凳、花盆、经幡、香案、书卷、茶具；
- 水边光秃：无石阶入水、无乌篷船、无亲水平台、水草芦苇稀疏；
- **没有柳树**——江南水乡第一标志物缺失；
- 无锦鲤（有鱼群函数但密度/色彩不足）、无落花浮水。

### C. 布局太规则
- 建筑群横平竖直（宫殿主轴可以，园林区必须"曲"）；
- 树木株距均匀，缺"三五成群、疏密有致"。

### D. 环境元素简陋
- 远山 = 低多边形锥体（distant_peak 单 ridge_spike 组），无山体质感；
- 云 = ico_mesh 椭球群，平面感；
- 水面仅材质，缺荷叶荷花密度、缺涟漪层次。

### E. 树木建模味
- 松针靠椭球团撑体积，轮廓太圆整；
- 枝干转折参数化太强（lean 单一）。

### F. 氛围单薄（黑神话侧）
- 当前明亮均匀，无体积雾层次、无戏剧性光束、暗部不死黑但也不深沉；
- 色彩分级缺失，统一灰调，无"晨钟暮鼓"的时段感。

## 二、改造主轴（待两路调研回填细化）

1. **材质系统重写**：多层 Noise（大斑块+中纹理+小细节）+ 方向性做旧（Z 渐变/水线）+ 全关键材质挂 procedural → "岁月感材质库"。
2. **燕云化组件大扩编**：柳树（垂枝新树型）、乌篷船、石阶入水、石桌凳、花盆、经幡、香案、加强锦鲤/落花、芦苇丛、水鸭。
3. **宋代形制精修**：斗拱加密（当前 bracket 较简）、窗棂纹样升级（lattice_window 当前 X 交叉太简）、栏杆加望柱头、台阶加垂带。
4. **布局有机化**：园林区路径曲化、树木聚群散布（泊松盘+簇）。
5. **环境升级**：远山加侵蚀纹理与层次、云改体积/片状云带、水面加近岸涟漪环。
6. **氛围黑神话化**：EEVEE 体积雾（薄）、世界光调暗+方向光塑形、合成器色彩分级（暗部青、亮部暖）、选择性 bloom。

## 四、验收标准（先生的尺子）

1. 一眼看不像程序化生成——有"人住过"的痕迹；
2. 材质近看有细节、中看有变化、远看有层次；
3. 规模：对象数从 852 冲 3000+（本轮），长期 10000；
4. 氛围：有雾的层次、光的戏剧、色的情绪；
5. 关系无错误：无悬浮、无穿模、无尺度失调（沿用看图门禁）。

## 六、燕云报告精华摘要（已读罢提炼）

### 建筑形制（消除盒子感的致命细节）
- **侧脚**：外檐柱首向内倾 1%（角柱双向 1.28%）；**生起**：角柱比明间柱高 2%；**卷杀**：柱上 1/3 收分 10%。
- **举折**：举高=进深/3.3，逐缝递折减半；**出檐深远**=柱高 1/3~1/2（宋远深于清）；角翘 15-22°。
- 斗拱硕大=柱高 1/3~1/2，每间仅 1-2 朵补间铺作（疏朗）。
- 格眼纹样：双交麻叶/四方透亮/三交六椀菱花/球纹/万字；**严禁明清步步锦冰裂**。
- 抱厦/十字歇山打破火柴盒立面。

### 材质做旧（直接可用的 RGB 表）
- 老木柱 (0.24-0.35, 0.14-0.22, 0.08-0.14) R0.45-0.85；**人手摩擦带 Z0.9-1.5m 降糙至 0.35、柱根 0.2m 湿润变黑 R0.95**。
- 青黛瓦 (0.12-0.19 灰调) **R0.75-0.95 哑光**（我们的琉璃瓦 R0.34 太亮了！）；瓦沟积灰、向北面青苔。
- 粉墙 (0.68-0.78 偏米黄灰) + **雨淋泪痕竖条**（Z 轴拉伸 noise）。
- 黄铜 (0.55,0.42,0.18) M0.85+，**缝隙孔雀绿锈 (0.10,0.42,0.32)**。
- 水际线分层：水线上 0.3m 深色水痕带 R0.18，水下墨绿水藻。

### 场景密度公式
- 泊松盘+路径衰减 `r_min(d)=r0*(1+k*d)`；旋转扰动 ±12°、下沉 ±0.03m、微倾 ±2.5°。
- 水巷：**水埠头每 15-25m 一处（宽 1.2-2m、入水 3-4 级、苔滑）、乌篷船 2-4 艘/50m（倾斜 5-8°）、晾衣竿、浮萍聚集 30-60%**。
- 宫观庭院：青铜香炉+青烟、鹤/龟蛇石刻、**石经幢+道家符幡**、盆景石臼（蓄水苔+枯竹叶）。
- 郊野：乱石分形聚集 8-15 块/100㎡、倒木灵芝、石龛。

### 植被
- **垂柳=江南灵魂**：干扭曲向水倾 20-40°、枝垂至水面上 0.3-0.8m、嫩黄绿/翠绿。
- 斑竹丛生（径 6-12cm 高 8-14m）、云片松、**荷塘三层（挺水荷叶 0.5-1.2m/浮水睡莲/残荷枯梗）**、苔藓 Sheen 0.6-0.8。

### 色彩与氛围
- **6:3:1**：60% 冷灰黛黑土石 + 30% 深木浓绿 + 10% 褪朱砂 #8A2825/藤黄 #C49C48/石青 #1E4E52 点睛。
- 太阳仰角 8-18° 低角度侧逆光+丁达尔；**地面带状薄雾 1-2m 掩桥船下半截**；水面双层涟漪（2m 大涟漪+0.15m 风纹）；倒影碎裂晕染。
