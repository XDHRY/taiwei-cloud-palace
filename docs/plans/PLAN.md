## 原则

1. **每轮必须新建。** 至少一类新建筑或一类新自然物（外岛、桥、亭、塔、瀑、鸟群、鱼群、灯廊）。禁止整轮只改相机或只改一个吻。
2. **每轮必须精修关系。** 新件落地后立刻看图，改位置、尺度、衔接。禁止只堆不调。
3. **计数要涨。** STATE 记录 `objects` 与上一轮差值。长期目标 ≥10000。STUDY 允许合批，但新类别必须有独立对象或独立合批名。
4. **成片 blend 不许被清空。** 重建只写 Expand。
5. **看图门禁。** plan / front / east，必要时加一张新件特写。主会话 Read。禁视觉 MCP。
6. **机器诚实。** MX450 2GB，EEVEE 审计。正片仍由先生双击过夜。
